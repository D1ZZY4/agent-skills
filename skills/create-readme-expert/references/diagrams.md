# Diagrams in READMEs

When the README needs a diagram (structure, flow, sequence, or architecture that prose
alone cannot carry), use the `mermaid-diagrams-expert` skill instead of hand-writing
Mermaid from memory. If that skill is not installed on the current harness, fetch it
from its canonical raw URL:

```text
https://raw.githubusercontent.com/D1ZZY4/agent-skills/refs/heads/main/skills/mermaid-diagrams-expert/SKILL.md
```

Reference files follow the same pattern. Replace `SKILL.md` with the reference path,
for example `references/flowcharts.md`.
